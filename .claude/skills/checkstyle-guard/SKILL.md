# Навык: Gradle Checkstyle Guard

## Описание
Навык перехватывает намерение сделать коммит в Java-проекте на Gradle, запускает локальный линтер и автоматически исправляет замечания по кодстайлу.

## Инструкции для Claude
1. Перед созданием коммита выполни команду проверки: `./gradlew checkstyleMain`.
2. Если сборка завершилась ошибкой (`BUILD FAILED`):
    - Найди в консоли пути к XML-отчетам Checkstyle (обычно в `build/reports/checkstyle/main.xml`).
    - Прочитай этот XML-файл, чтобы узнать точные строки и типы ошибок (например, `UnusedImports`, `LineLength`, `Indentation`).
    - Исправь исходный код в целевых файлах Java.
    - Повторно запусти `./gradlew checkstyleMain`, чтобы убедиться, что ошибок больше нет.
3. Если проект слишком большой и сборка идет долго, ты можешь использовать точечную проверку (если в вашем `build.gradle` настроен соответствующий таск): `./gradlew checkstyleMain --include-only` для измененных файлов, которые ты видишь через `git status`.
4. Не делай коммит, пока Gradle не вернет `BUILD SUCCESSFUL`.
